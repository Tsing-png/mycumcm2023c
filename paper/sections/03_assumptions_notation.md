# 模型假设与符号说明

## 模型假设

| 编号 | 假设 | 类型 | 依据 |
|---|---|---|---|
| A1 | 蔬菜当日未售出则隔日无法再售，每日为一独立库存周期 | 必要 | 题目原话 |
| A2 | 定价采用成本加成定价：$P = (1+\alpha)C$ | 必要 | 题目明确要求 |
| A3 | 打折为被动清仓行为，折扣回收率$k=0.66$（数据中位数） | 简化 | 人工确认；报告$k\in[0.50,0.75]$区间 |
| A4 | 历史销售数据可代表未来需求趋势 | 必要 | 所有时序模型的基础 |
| A5 | 损耗率在预测期内恒定 | 简化 | 题目仅提供近期盘点值 |
| A6 | 退货可忽略（0.05%） | 简化 | 数据审计验证 |
| A7 | Q2以品类为单位不考虑销售空间约束 | 简化 | 题目仅在Q3提出；人工确认 |

## 符号说明

| 符号 | 含义 | 单位 |
|---|---|---|
| $i$ | 品类索引，$i=1,\ldots,6$ | — |
| $j$ | 单品索引 | — |
| $t$ | 日期索引 | 天 |
| $S_{i,t}$ | 品类$i$在第$t$天的总销售量 | kg |
| $\rho_{ab}$ | 品类$a$与$b$的Spearman秩相关系数 | — |
| $\hat{D}_{i,t}$ | Prophet对品类$i$在第$t$天的需求预测 | kg |
| $\alpha_{i,t}$ | 品类$i$在第$t$天的加成率（决策变量） | — |
| $P_{i,t}$ | 品类$i$在第$t$天的销售定价 | 元/kg |
| $Q_{i,t}$ | 品类$i$在第$t$天的订货量（决策变量） | kg |
| $C_{i,t}$ | 品类$i$在第$t$天的批发价（成本） | 元/kg |
| $C_{i,t}^{\text{eff}}$ | 有效成本：$C_{i,t}/(1-L_i)$ | 元/kg |
| $L_i$ | 品类$i$的平均损耗率 | — |
| $k$ | 折扣回收率（打折价/正价） | — |
| $e_i$ | 品类$i$的需求价格弹性 | — |
| $\pi_{i,t}$ | 品类$i$在第$t$天的期望利润 | 元 |
| $\Pi$ | 总利润 | 元 |
| $\gamma_i$ | 品类$i$的需求满足率 | — |
| $d_{\min}$ | 最小陈列量（2.5 kg） | kg |
| $N$ | 入选单品数 | 个 |

完整符号表见支撑材料。
