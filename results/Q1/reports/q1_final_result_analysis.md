## 1. 品类间 Spearman 秩相关分析

对 6 个品类的日销售量（1049 天）计算 Spearman 秩相关系数矩阵：

| | 水生根茎类 | 花叶类 | 花菜类 | 茄类 | 辣椒类 | 食用菌 |
|---|---|---|---|---|---|---|
| **水生根茎类** | 1.000 | 0.430 | 0.389 | −0.194 | 0.315 | 0.602 |
| **花叶类** | | 1.000 | 0.625 | 0.325 | 0.584 | 0.590 |
| **花菜类** | | | 1.000 | 0.235 | 0.416 | 0.457 |
| **茄类** | | | | 1.000 | 0.154 | −0.091 |
| **辣椒类** | | | | | 1.000 | 0.524 |
| **食用菌** | | | | | | 1.000 |

- ρ 范围：[−0.194, 0.625]，均值 |ρ| = 0.395
- **最强正相关**：花叶类↔花菜类 (ρ=0.625)，花叶类↔食用菌 (ρ=0.590)
- **唯一负相关**：茄类↔水生根茎类 (ρ=−0.194)，茄类↔食用菌 (ρ=−0.091)
- 茄类与其他品类的关联普遍较弱（|ρ| < 0.33），说明茄类需求相对独立

**统计学意义**：全部 6 品类拒绝正态性原假设（D'Agostino-Pearson, p < 10⁻⁷⁵），Pearson 相关系数假设不成立。Pearson 与 Spearman 方向一致性为 86.7%（13/15 对），最大差异 0.299（水生根茎类↔花菜类）。

## 2. 聚类分析

使用 K-means++ 对 159 个销售天数 ≥ 30 的单品按 (平均销量, 销量标准差, 变异系数, 平均售价) 聚类：

| 指标 | 值 |
|---|---|
| 最优 K | 2（Silhouette = 0.463） |
| 簇 0（72 单品） | 低销量 (2.2 kg/天)、高波动 (CV=0.76)、高价格 (12.96 元/kg) |
| 簇 1（87 单品） | 高销量 (12.4 kg/天)、中等波动 (CV=0.83)、低价格 (6.18 元/kg) |

簇 0 以辣椒类和食用菌为主，簇 1 以花叶类为主。两个簇均包含全部 6 个品类，说明品类内部也存在销量分化。

## 3. 分布拟合

各品类日销售量的最优拟合分布：

| 品类 | 最优分布 | KS p 值 |
|---|---|---|
| 花叶类 | 对数正态 | 0.544 |
| 花菜类 | 对数正态 | 0.879 |
| 茄类 | 对数正态 | 0.991 |
| 辣椒类 | 对数正态 | 0.431 |
| 食用菌 | 对数正态 | 0.294 |
| 水生根茎类 | 对数正态 | 0.008 |

水生根茎类 KS p = 0.008（拒绝对数正态），其他 5 个品类不拒绝。总体而言，对数正态是对蔬菜日销售量最适用的分布族。

## 4. 季节性模式

月度销售量趋势图显示：花叶类在 11 月达到峰值（~250 kg/天），花菜类和食用菌在秋冬季节（10–12 月）销售旺盛，水生根茎类和茄类季节性较弱。该结果与高佳楠 et al. (2024) 报告的采收季分布一致。

## 5. 跨年稳定性

| 年份 | 平均 |ρ| | 与次年 ρ 向量相关 |
|---|---|---|---|
| 2020 | 0.357 | r = 0.824 (→2021) |
| 2021 | 0.387 | r = 0.168 (→2022) |
| 2022 | 0.530 | — |

2020-2021 年关联结构稳定，2021-2022 年变化主要源于茄类的持续萎缩（日均销量 26→22→19 kg）和疫情后消费模式调整。

## 6. 对 Q2/Q3 的传导

- 花叶类、花菜类、食用菌、辣椒类间存在中等正相关 → Q2 可考虑品类联动
- 茄类与其他品类关联弱 → 可独立建模
- 两簇结构 (低量高波动 vs 高量中波动) → Q3 单品选择需兼顾两类
